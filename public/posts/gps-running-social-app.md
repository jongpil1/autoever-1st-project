# GPS 기반 러닝 소셜앱
---

## 📌 프로젝트 개요
위치 기반 기술과 사용자 간 상호작용을 결합한 실시간 커뮤니티 기반 러닝 트래킹 모바일 애플리케이션

### Github 레파지토리
- [https://github.com/jongpil1/runwith](https://github.com/jongpil1/runwith)

### 목표

기존 러닝 앱들은 단순 기록 통계와 위치 추적에 치중되어 있어, 사용자 간 정서적 교류와 실시간 상호작용이 가능한 러닝 앱을 만들고자 하였습니다.

### 주요 기능

- 주변 러너들과 GPS 기반 실시간 위치 공유
- 일정 거리 이내로 접근한 사용자 간 하이파이브 이벤트
- 러닝 종료 후 코스 및 러닝 기록을 포함한 포스트 자동 생성
- 러닝 기록을 기반으로 한 소셜 피드
- 댓글 및 좋아요를 통한 러너 간 커뮤니케이션

## 🔧 기술 스택

### Frontend

- **React Native**

### Backend

- **Node.js**
  - 프론트엔드와 동일한 JavaScript 환경을 사용하여 개발 효율을 높이고 RESTful API 서버를 구축하였습니다.

- **MongoDB & Mongoose**
  - Mongoose ODM을 활용하여 `User`, `Post`, `Run` 등의 데이터 모델을 설계하고 데이터 관계를 정의하였습니다.

- **JSON Web Token (JWT)**
  - JWT 기반 인증 시스템을 구현하여 로그인 상태를 안전하게 관리하도록 하였습니다.

- **Socket.io**
  - 댓글 추가 및 사용자 간 상호작용을 실시간으로 반영하기 위해 이벤트 기반 양방향 통신 구조를 적용하였습니다.

- **Google Maps SDK**
  - GPS 정보를 기반으로 사용자의 이동 경로를 지도에 표시하고 러닝 데이터를 처리하는 데 활용하였습니다.

## 🖥️ 핵심 기능

### 1. 실시간 위치 처리

Google Maps SDK와 GPS를 연동하여 사용자의 이동 경로를 실시간으로 수집하고, 이동 거리와 페이스를 계산하는 기능을 구현하였습니다.

또한 주변 러너들의 위치를 실시간으로 공유하여 사용자 간 상호작용이 가능하도록 구성하였습니다.

### 2. 하이파이브 이벤트

사용자 간 거리를 기반으로 일정 거리 이내에 두 러너가 접근하면 하이파이브 이벤트가 발생하도록 구현하였습니다.

이를 통해 단순한 러닝 기록을 넘어 실제 러닝 중 다른 사용자와 상호작용할 수 있도록 하였습니다.

### 3. 인증 및 백엔드 인프라 설계

Node.js 기반 백엔드 서버를 구축하고 JWT 기반 인증 시스템을 적용하였습니다.

MongoDB와 Mongoose를 활용하여 사용자, 친구, 러닝 기록, 하이파이브 기록, 피드 등의 데이터를 관리할 수 있도록 데이터베이스 구조를 설계하였습니다.

### 4. 러닝 기록 공유 및 커뮤니티

러닝 종료 후 거리, 페이스, 경로 등의 러닝 기록을 소셜 피드에 자동으로 게시할 수 있도록 구현하였습니다.

또한 댓글 및 좋아요 기능을 위한 REST API를 구현하여 러너들이 러닝 기록을 공유하고 소통할 수 있도록 하였습니다.
