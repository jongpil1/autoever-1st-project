# React Spring Library

---

## 📌 프로젝트 개요

React와 Spring Boot를 기반으로 구축한 도서 관리 웹 애플리케이션입니다.

프론트엔드와 백엔드를 분리하여 REST API 기반으로 통신하도록 구성하였으며, 사용자의 도서 데이터를 데이터베이스에서 관리할 수 있도록 구현하였습니다.

### 목표

React 기반의 프론트엔드와 Spring Boot 기반의 백엔드를 연동하여 실제 웹 서비스에서 사용되는 REST API 구조와 데이터 처리 과정을 경험하고, 사용자와 도서 데이터를 효율적으로 관리할 수 있는 서비스를 구현하고자 하였습니다.

### 주요 기능

- 회원가입 및 로그인
- 사용자 정보 관리
- 도서 목록 조회
- 도서 상세 정보 조회
- 도서 등록 및 관리
- REST API를 통한 프론트엔드와 백엔드 통신
- 데이터베이스 기반 데이터 관리

## 🔧 기술 스택

### Frontend

- **React**
  - 컴포넌트 기반으로 사용자 인터페이스를 구성하였습니다.
  - REST API를 통해 Spring Boot 백엔드와 데이터를 주고받도록 구현하였습니다.

### Backend

- **Spring Boot**
  - REST API 서버를 구축하고 비즈니스 로직을 처리하도록 구성하였습니다.

- **Spring Data JPA**
  - 객체와 데이터베이스 테이블을 매핑하여 회원 및 도서 데이터를 관리하였습니다.
  - Repository를 활용하여 데이터 조회 및 저장 로직을 구현하였습니다.

- **Spring Security**
  - 사용자 인증 및 접근 제어를 위한 보안 설정을 구성하였습니다.

- **JWT**
  - 로그인 이후 사용자의 인증 상태를 유지하기 위해 JWT 기반 인증 구조를 적용하였습니다.

### Database

- **MySQL / PostgreSQL**
  - 사용자 및 도서 데이터를 저장하고 관리하였습니다.

## 🖥️ 핵심 기능

### 1. 회원가입 및 로그인

사용자가 회원가입을 통해 계정을 생성할 수 있도록 구현하였습니다.

로그인 시 사용자의 인증 정보를 검증하고 JWT를 발급하여 이후 API 요청에서 사용자를 인증할 수 있도록 구성하였습니다.

### 2. 사용자 관리

사용자 정보를 데이터베이스에 저장하고 조회할 수 있도록 REST API를 구현하였습니다.

회원 관련 데이터를 JPA Entity와 Repository를 통해 관리하여 데이터베이스 접근 로직을 객체지향적으로 구성하였습니다.

### 3. 도서 관리

도서 데이터를 등록하고 조회할 수 있는 CRUD 기능을 구현하였습니다.

REST API를 통해 도서 목록 및 상세 정보를 조회하고, 필요한 경우 도서 데이터를 추가하거나 수정할 수 있도록 구성하였습니다.

### 4. REST API 기반 통신

React 프론트엔드와 Spring Boot 백엔드를 분리하여 REST API를 통해 데이터를 주고받도록 구현하였습니다.

프론트엔드에서 API 요청을 보내면 Spring Boot의 Controller → Service → Repository 계층을 거쳐 데이터베이스에 접근하고 결과를 다시 프론트엔드에 반환하는 구조로 구성하였습니다.

### 5. 인증 및 보안

Spring Security를 활용하여 API 접근 권한을 관리하고 JWT 기반 인증 구조를 구현하였습니다.

로그인 이후 발급된 Access Token을 API 요청에 포함하여 인증된 사용자만 필요한 기능에 접근할 수 있도록 구성하였습니다.
