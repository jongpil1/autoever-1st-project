# 개발자 포트폴리오

---

## 📌 프로젝트 개요

React와 TypeScript를 기반으로 개발한 개인 개발자 포트폴리오 웹 애플리케이션입니다.

자기소개, 기술 스택, 프로젝트 및 경력 등의 정보를 한 곳에서 확인할 수 있도록 구성하였으며, 각 프로젝트의 상세 README를 제공하여 프로젝트의 개발 과정과 주요 기능을 확인할 수 있도록 구현하였습니다.

또한 프로젝트별 AI 챗봇을 추가하여 GitHub Repository의 프로젝트 코드와 커밋 내용을 기반으로 프로젝트에 대해 질문하고 답변을 받을 수 있는 기능을 구현하고 있습니다.

## 🔧 기술 스택

### Frontend

* **React**

  * 컴포넌트 기반으로 포트폴리오 UI를 구성하였습니다.
  * 페이지와 기능을 컴포넌트 단위로 분리하여 재사용성과 유지보수성을 고려하였습니다.

* **TypeScript**

  * 컴포넌트 Props와 데이터에 타입을 정의하여 안정적인 코드 작성이 가능하도록 구성하였습니다.

* **TanStack Query**

  * 외부 API를 통해 프로젝트 및 GitHub 관련 데이터를 조회하고 서버 상태를 관리하기 위해 사용하였습니다.

* **CSS Modules**

  * 컴포넌트별 스타일을 모듈화하여 CSS 클래스 간의 전역 충돌을 방지하였습니다.

### AI

* **AI API**

  * 프로젝트의 GitHub Repository 내용을 기반으로 사용자의 질문에 답변할 수 있는 AI 챗봇을 구현하고 있습니다.
  * 프로젝트 코드와 커밋 내용을 활용하여 단순한 포트폴리오 정보뿐만 아니라 실제 개발 과정에 대한 질문에도 답변할 수 있도록 구성하고 있습니다.

### GitHub

* **GitHub API**

  * 프로젝트 Repository의 정보와 커밋 데이터를 조회하는 데 활용합니다.
  * 프로젝트별 Repository를 기반으로 AI 챗봇이 프로젝트의 개발 과정과 변경 내용을 이해할 수 있도록 구성하고 있습니다.

### Deployment

* **Vercel**

  * React 기반 프론트엔드 애플리케이션을 배포하였습니다.

## 🖥️ 핵심 기능

### 1. 자기소개

개발자의 기본 정보와 한 줄 소개를 제공하여 방문자가 개발자의 주요 관심 분야와 기술 역량을 빠르게 확인할 수 있도록 구성하였습니다.

프로필, 소개 정보, 기술 스택 등을 각각의 컴포넌트로 분리하여 관리하였습니다.

### 2. 기술 스택

사용할 수 있는 기술을 `Language`, `Frontend`, `Backend`, `DevOps` 등의 카테고리로 구분하여 보여주도록 구현하였습니다.

각 카테고리를 카드 형태로 구성하고 서로 다른 색상을 적용하여 기술 영역을 직관적으로 확인할 수 있도록 구성하였습니다.

### 3. 프로젝트 목록

프로젝트를 카드 형태로 구성하여 프로젝트 제목, 설명 및 주요 정보를 한눈에 확인할 수 있도록 구현하였습니다.

각 프로젝트의 상세 정보를 확인할 수 있도록 README 조회 기능과 AI 챗봇을 연결할 수 있는 구조로 구성하였습니다.

### 4. README 조회

각 프로젝트의 README 버튼을 클릭하면 해당 프로젝트의 Markdown 문서를 Modal 형태로 확인할 수 있도록 구현하였습니다.

프로젝트별 Markdown 파일을 `public` 폴더에서 관리하고 프로젝트의 `slug`를 기준으로 해당 README 파일을 불러오도록 구성하였습니다.

### 5. GitHub Repository 연동

각 프로젝트에 연결된 GitHub Repository를 활용하여 프로젝트의 실제 개발 내용을 확인할 수 있도록 구성하였습니다.

Repository의 커밋 내역과 프로젝트 관련 정보를 활용하여 단순히 완성된 결과만 보여주는 것이 아니라 프로젝트의 개발 과정까지 확인할 수 있도록 구현하고 있습니다.

### 6. 프로젝트별 AI 챗봇

각 프로젝트에 AI 챗봇을 연결하여 해당 프로젝트에 대한 질문을 할 수 있도록 구현하고 있습니다.

AI 챗봇은 프로젝트에 연결된 GitHub Repository의 코드와 커밋 내용 등을 기반으로 프로젝트의 기능과 개발 과정에 대한 질문에 답변할 수 있도록 구성합니다.

예를 들어 다음과 같은 질문을 할 수 있습니다.

* "이 프로젝트에서 JWT 인증은 어떻게 구현했나요?"
* "가장 최근에 추가한 기능은 무엇인가요?"
* "React Query를 사용한 이유가 무엇인가요?"
* "이 프로젝트에서 가장 중요한 기술은 무엇인가요?"
* "이 기능은 어떤 커밋에서 추가되었나요?"

이를 통해 방문자가 README를 직접 읽는 것뿐만 아니라 **AI와 대화하면서 프로젝트를 탐색할 수 있도록 하는 것**을 목표로 합니다.

### 7. 반응형 웹 디자인

데스크톱뿐만 아니라 다양한 화면 크기에서도 콘텐츠를 확인할 수 있도록 반응형 레이아웃을 적용하였습니다.

CSS Grid와 Flexbox를 활용하여 프로젝트 카드와 기술 스택 등의 레이아웃을 구성하고 화면 크기에 따라 적절하게 변경되도록 구현하였습니다.
